2.1Divisibility and the Division Algorithm

The vocabulary every later section uses: “divides”, “divisor”, “remainder/residue”.

Divides. A nonzero integer b divides a, written b | a, if a = mb for some integer m — i.e., dividing leaves no remainder. Then b is a divisor of a.
Example
Positive divisors of 24: 1, 2, 3, 4, 6, 8, 12, 24 13 | 182 −5 | 30 17 | 289 −3 | 33 17 | 0

Properties of divisibility

  • If a | 1, then a = ±1.
  • If a | b and b | a, then a = ±b.
  • Any b ≠ 0 divides 0.
  • If a | b and b | c, then a | c (e.g., 11 | 66 and 66 | 198 ⇒ 11 | 198).
  • If b | g and b | h, then b | (mg + nh) for any integers m, n.
    Why: g = b·g₁ and h = b·h₁, so mg + nh = b(mg₁ + nh₁).

The division algorithm

For any positive integer n and any integer a, dividing a by n gives a unique quotient q and remainder r:

a = qn + r, 0 ≤ r < n, q = ⌊a / n⌋ (2.1)

⌊x⌋ is the largest integer ≤ x. The remainder r is also called the residue. (Despite the name, Eq. 2.1 is a theorem, not an algorithm.) Because q uses the floor, r is never negative, even when a is: −11 = (−2)·7 + 3, so r = 3.

2.2The Euclidean Algorithm

A fast way to find the greatest common divisor without factoring — used constantly in cryptography.

Greatest common divisor. gcd(a, b) is the largest integer that divides both a and b. Formally, a positive integer c is the gcd if (1) c divides a and b, and (2) every divisor of a and b divides c.
Equivalently: gcd(a, b) = max[k such that k | a and k | b].
  • The gcd is positive, so gcd(a, b) = gcd(|a|, |b|); e.g., gcd(60, −24) = 12.
  • All nonzero integers divide 0, so gcd(a, 0) = |a|. By definition gcd(0, 0) = 0.
Relatively prime. Two integers are relatively prime if their only common positive divisor is 1, i.e., gcd(a, b) = 1. Example: 8 (divisors 1, 2, 4, 8) and 15 (divisors 1, 3, 5, 15).

How it works

The key fact (Eq. 2.6, Section 2.3): for integers a ≥ b ≥ 0,

gcd(a, b) = gcd(b, a mod b) (2.6)

Why: any common divisor d of a and b also divides a − kb = a mod b; conversely, a common divisor of b and a mod b divides kb + (a mod b) = a. Both pairs share the same set of common divisors, so they share the same gcd. Repeat until the remainder is 0; the last nonzero remainder is the gcd. The remainders strictly decrease, so the process always ends.

Flow of the algorithm (adapted from Fig. 2.2). Recursive form: Euclid(a,b): if b = 0 return a; else return Euclid(b, a mod b).
Example · gcd(710, 310) (Fig. 2.3)
710 = 2 × 310 + 90 310 = 3 × 90 + 40 90 = 2 × 40 + 10 40 = 4 × 10 + 0 ⇒ gcd = 10

Each line has the same gcd as the line above it. The book also works gcd(1160718174, 316258250) = 1078 in 10 steps (Table 2.1) — try it below.

2.3Modular Arithmetic

Arithmetic that “wraps around” inside the finite set {0, 1, …, n−1}. Nearly every algorithm in the book works this way.

Modulus and a mod n. For integer a and positive integer n, a mod n is the remainder when a is divided by n; n is the modulus. So a = ⌊a/n⌋ × n + (a mod n).
Examples: 11 mod 7 = 4; −11 mod 7 = 3.
Congruent modulo n. a ≡ b (mod n) if (a mod n) = (b mod n). Examples: 73 ≡ 4 (mod 23); 21 ≡ −9 (mod 10). If a ≡ 0 (mod n), then n | a.
Try it · the mod-n clock
Starting at 0, take |a| steps (clockwise if a > 0, counter-clockwise if a < 0). Where you land is a mod n. All integers that land on the same mark are congruent mod n.

Two meanings of “mod” (Appendix 2A)

Binary operator. a mod n = a − ⌊a/n⌋ × n returns a number: 7 mod 3 = 1. Written without parentheses around “mod”.
Congruence relation. 7 ≡ 4 (mod 3) is a true/false statement: 7 and 4 leave the same remainder, i.e. 3 | (7 − 4). Written with ≡ and “(mod n)” in parentheses.

Properties of congruences

  1. a ≡ b (mod n) if n | (a − b).  e.g. 23 ≡ 8 (mod 5) because 23 − 8 = 15 = 5 × 3; −11 ≡ 5 (mod 8) because −16 = 8 × (−2).
  2. a ≡ b (mod n) implies b ≡ a (mod n).
  3. a ≡ b and b ≡ c (mod n) imply a ≡ c (mod n).

Modular arithmetic operations

You may reduce before or after adding, subtracting, or multiplying — the result is the same:

[(a mod n) + (b mod n)] mod n = (a + b) mod n [(a mod n) − (b mod n)] mod n = (a − b) mod n [(a mod n) × (b mod n)] mod n = (a × b) mod n
Example · exponentiation by repeated multiplication
Find 11⁷ mod 13: 11² = 121 ≡ 4 (mod 13) 11⁴ = (11²)² ≡ 4² ≡ 3 (mod 13) 11⁷ = 11 × 11² × 11⁴ ≡ 11 × 4 × 3 = 132 ≡ 2 (mod 13)

Zn and residue classes

Zn is the set of nonnegative integers less than n: Zn = {0, 1, …, n − 1}, the set of residues mod n. Each element r stands for a residue class [r] = {a : a ≡ r (mod n)}.
Reducing k modulo n means finding the smallest nonnegative integer congruent to k, which is the class representative.
Residue classes mod 4
[0] = {…, −8, −4, 0, 4, 8, …} [1] = {…, −7, −3, 1, 5, 9, …} [2] = {…, −6, −2, 2, 6, 10, …} [3] = {…, −5, −1, 3, 7, 11, …}

Within Zn the usual laws hold (Table 2.3): commutative, associative and distributive laws, identities (0 + w) mod n = w mod n and (1 × w) mod n = w mod n, and every w has an additive inverse. (Section 5 calls such a structure a commutative ring with a multiplicative identity.)

Additive inverse of x: the y with (x + y) mod n = 0; always exists.
Multiplicative inverse of x, written x⁻¹: the y with (x × y) mod n = 1; does not always exist.

The one big difference from ordinary arithmetic

if (a + b) ≡ (a + c) (mod n),
then b ≡ c (mod n)always(2.4)
if (a × b) ≡ (a × c) (mod n),
then b ≡ c (mod n)only if gcd(a, n) = 1(2.5)

Counterexample: 6 × 3 = 18 ≡ 2 and 6 × 7 = 42 ≡ 2 (mod 8), yet 3 ≢ 7 (mod 8). Multiplying Zn by an a that shares a factor with n is many-to-one, so it cannot be undone.

Try it · multiply every element of Z₈ by a
Rule. An integer has a multiplicative inverse in Zn if and only if it is relatively prime to n.

The extended Euclidean algorithm

Besides d = gcd(a, b), it finds integers x, y (opposite signs) with

ax + by = d = gcd(a, b) (2.7)

The smallest positive value of ax + by equals gcd(a, b). Track each remainder as rᵢ = a·xᵢ + b·yᵢ. Start with r₋₁ = a (x=1, y=0) and r₀ = b (x=0, y=1), then for each row:

qᵢ = ⌊rᵢ₋₂ / rᵢ₋₁⌋ rᵢ = rᵢ₋₂ mod rᵢ₋₁ xᵢ = xᵢ₋₂ − qᵢ·xᵢ₋₁ yᵢ = yᵢ₋₂ − qᵢ·yᵢ₋₁ Stop when rᵢ = 0. The previous row gives d, x, y.

Why it matters: when gcd(a, n) = 1, the result ax + ny = 1 means ax ≡ 1 (mod n), so x mod n is the multiplicative inverse of a. This is how inverses are computed for finite fields and RSA.

2.4Prime Numbers

Primes are the building blocks of all integers, and the hardness of working backwards from a product of primes underlies public-key cryptography.

Prime. An integer p > 1 whose only divisors are ±1 and ±p. Composite: an integer > 1 that is not prime.

Fundamental theorem of arithmetic

Every integer a > 1 factors uniquely as

a = p₁^a₁ × p₂^a₂ × … × pₜ^aₜ, p₁ < p₂ < … < pₜ prime, each aᵢ ≥ 1 (2.9)
Examples
91 = 7 × 13 3600 = 2⁴ × 3² × 5² 11011 = 7 × 11² × 13

Equivalently, write a = ∏ p^(aₚ) over all primes, where most exponents aₚ are 0. A number is then just its list of nonzero exponents — 12 is {a₂ = 2, a₃ = 1}; 18 is {a₂ = 1, a₃ = 2}. This turns three operations into exponent arithmetic:

OperationIn exponentsExample
Multiply: k = abkₚ = aₚ + bₚ12 × 18 = (2²·3)(2·3²) = 2³·3³ = 216
Divide: a | baₚ ≤ bₚ for every p12 = 2²·3 divides 36 = 2²·3²
gcd: k = gcd(a, b)kₚ = min(aₚ, bₚ)gcd(18, 300) = gcd(2·3², 2²·3·5²) = 2·3 = 6
Factoring a large number is hard, so the min-exponent rule is not a practical way to compute a gcd. Use the Euclidean algorithm instead.

2.5Fermat’s and Euler’s Theorems

Both theorems play important roles in public-key cryptography (RSA relies directly on Euler’s theorem).

Fermat’s theorem

Fermat. If p is prime and a is a positive integer not divisible by p:
a^(p−1) ≡ 1 (mod p) (2.10) a^p ≡ a (mod p) (any positive a) (2.11)

Proof idea. Multiplying each of {1, 2, …, p − 1} by a mod p gives the same set reordered (no zeros, because p ∤ a; no repeats, by Eq. 2.5). Multiply all elements of both sets: a^(p−1)·(p−1)! ≡ (p−1)! (mod p). Cancel (p−1)!, which is relatively prime to p.

Examples
a = 7, p = 19: 7² ≡ 11, 7⁴ ≡ 7, 7⁸ ≡ 11, 7¹⁶ ≡ 7 7¹⁸ = 7¹⁶ × 7² ≡ 7 × 11 = 77 ≡ 1 (mod 19) ✓ p = 5, a = 3: 3⁵ = 243 ≡ 3 (mod 5) p = 5, a = 10: 10⁵ ≡ 10 ≡ 0 (mod 5) ← form (2.11) works even when p | a

Euler’s totient function φ(n)

φ(n) = the number of positive integers less than n that are relatively prime to n. By convention φ(1) = 1.
  • For prime p: φ(p) = p − 1 (every number below p qualifies).
  • For distinct primes p, q: φ(pq) = φ(p) × φ(q) = (p − 1)(q − 1).
    Why: of the pq − 1 numbers below pq, the ones sharing a factor are the (q − 1) multiples of p and the (p − 1) multiples of q, and these sets don’t overlap. So φ = (pq − 1) − (q − 1) − (p − 1) = (p − 1)(q − 1).
  • From the end-of-chapter problems: φ(pⁱ) = pⁱ − pⁱ⁻¹ for prime p (Prob. 2.26), and φ(mn) = φ(m)φ(n) when gcd(m, n) = 1 (Prob. 2.27).
Try it · count φ(n)
Highlighted cells are relatively prime to n. Book examples: φ(37) = 36, φ(35) = 24, φ(21) = φ(3)·φ(7) = 12.

Euler’s theorem

Euler. For every a and n that are relatively prime:
a^φ(n) ≡ 1 (mod n) (2.12) a^(φ(n)+1) ≡ a (mod n) (gcd not required) (2.13)

Fermat’s theorem is the special case where n is prime (φ(p) = p − 1). The proof is the same idea: multiplying the φ(n) integers coprime to n by a mod n just reorders them (a permutation — an ordered sequence of all the elements of a set, each appearing exactly once).

Examples
a = 3, n = 10: φ(10) = 4, 3⁴ = 81 ≡ 1 (mod 10) a = 2, n = 11: φ(11) = 10, 2¹⁰ = 1024 ≡ 1 (mod 11)

2.6Testing for Primality

Many algorithms need very large random primes, so we need a fast way to check whether a big number is prime.

Setup

Any odd n ≥ 3 can be written n − 1 = 2ᵏq with k > 0, q odd: keep halving n − 1 until the result is odd (in binary, shift right until the last bit is 1).

Two properties of primes

  1. If p is prime and a < p: a² mod p = 1 ⇔ a mod p = 1 or a mod p = p − 1 (i.e. −1).
  2. If p > 2 is prime, p − 1 = 2ᵏq, and 1 < a < p − 1, then either a^q ≡ 1 (mod p), or one of a^q, a^(2q), a^(4q), …, a^(2^(k−1) q) is ≡ −1 (mod p).

Why (2): by Fermat, the last term of the sequence a^q, a^(2q), …, a^(2^k q) = a^(p−1) is 1, and each term is the square of the one before. So either the first term is already 1, or some term ≠ 1 squares to 1 — and by property (1) that term must be p − 1.

The Miller–Rabin TEST(n)

1. Find k > 0, q odd, with n − 1 = 2ᵏq 2. Pick a random integer a, 1 < a < n − 1 3. if a^q mod n = 1 then return "inconclusive" 4. for j = 0 to k − 1 do 5. if a^(2ʲq) mod n = n − 1 then return "inconclusive" 6. return "composite"
Reading the output. “Composite” means n is definitely not prime. “Inconclusive” means n may or may not be prime. Example: 2047 = 23 × 89 passes with a = 2 (2¹⁰²³ mod 2047 = 1), but it is composite.
Try it · run TEST(n) with a chosen a

Using it repeatedly

For an odd composite n and random a, the chance TEST wrongly returns “inconclusive” is less than 1/4. With t independent choices of a, the chance a composite passes them all is less than (1/4)ᵗ — for t = 10, under 10⁻⁶. Procedure: run TEST with random a; if it ever says composite, reject; if it says inconclusive t times for large enough t, accept n as prime. (For 221, only 4 of the 218 bases 2–219 fool the test: 21, 47, 174, 200.)

Deterministic option: the AKS algorithm proves primality efficiently and without probability, but it appears less efficient than Miller–Rabin and has not replaced it.

Distribution of primes

The prime number theorem: primes near n are spaced on average one every ln(n) integers. Skipping even numbers, expect about 0.5 ln(n) candidates before finding a prime — e.g. near 2²⁰⁰, about 0.5 ln(2²⁰⁰) ≈ 69 trials. This is only an average: 1,000,000,000,061 and …063 are both prime, while 1001! + 2, …, 1001! + 1001 is a run of 1000 composites.

2.7The Chinese Remainder Theorem (CRT)

Work with one huge number mod M as a tuple of small numbers mod its factors, then convert back.

Intuition

Any digit 0–9 is pinned down by its remainders mod 2 and mod 5 (relatively prime factors of 10). If x mod 2 = 0 and x mod 5 = 3, the only digit is x = 8.

Pairwise relatively prime. Moduli m₁, …, mₖ with gcd(mᵢ, mⱼ) = 1 for every i ≠ j. Let M = m₁ × m₂ × … × mₖ.

Represent any A ∈ ZM by its residues:

A ↔ (a₁, a₂, …, aₖ), where aᵢ = A mod mᵢ (2.15)
Bijection. A one-to-one correspondence: every element on one side matches exactly one element on the other side, and vice versa.

The CRT makes two assertions:

  1. The mapping (2.15) is a bijection between ZM and Zm₁ × … × Zmₖ: each A in [0, M) has exactly one tuple, and each tuple comes from exactly one A.
  2. +, −, × on elements of ZM can be done independently in each coordinate (each mod its own mᵢ).

Converting back (tuple → A)

Mᵢ = M / mᵢ (Mᵢ ≡ 0 mod mⱼ for j ≠ i) cᵢ = Mᵢ × (Mᵢ⁻¹ mod mᵢ) (2.16) A ≡ (a₁c₁ + a₂c₂ + … + aₖcₖ) (mod M) (2.17)

This works because cᵢ ≡ 1 (mod mᵢ) and cⱼ ≡ 0 (mod mᵢ) for j ≠ i. Mᵢ is relatively prime to mᵢ, so its inverse exists (find it with the extended Euclidean algorithm). Catch: you must already know the factorization of M.

2.8Discrete Logarithms

The “hard direction” behind Diffie–Hellman key exchange and the Digital Signature Algorithm (DSA).

Powers of an integer, modulo n

If gcd(a, n) = 1, Euler guarantees at least one m with a^m ≡ 1 (mod n), namely m = φ(n).

Order. The least positive exponent m with a^m ≡ 1 (mod n). Also called “the exponent to which a belongs (mod n)” or “the length of the period generated by a”. The powers of a repeat with this period: e.g. 7¹ ≡ 7, 7² ≡ 11, 7³ ≡ 1 (mod 19), then 7, 11, 1, … again.
Primitive root. The highest possible order mod n is φ(n). An a with order φ(n) is a primitive root of n: its powers a, a², …, a^φ(n) are all distinct mod n and all relatively prime to n. For prime p, a primitive root generates every nonzero residue 1 … p − 1.

Only integers of the form 2, 4, pᵃ, 2pᵃ (p an odd prime) have primitive roots. Primitive roots of 19: 2, 3, 10, 13, 14, 15.

Logarithms for modular arithmetic

Discrete logarithm (index). For a primitive root a of prime p and any integer b, there is a unique exponent i with b ≡ aⁱ (mod p), 0 ≤ i ≤ p − 1. This i is dloga,p(b). (“Index” is another name; there is no agreed notation.)
dlog_a,p(1) = 0 (2.21) dlog_a,p(a) = 1 (2.22) dlog_a,p(xy) ≡ dlog_a,p(x) + dlog_a,p(y) (mod φ(p)) dlog_a,p(yʳ) ≡ r × dlog_a,p(y) (mod φ(p))

These mirror ordinary log rules, except exponents live mod φ(p) (by Euler, a^z ≡ a^q when z ≡ q mod φ(n)). Unique discrete logs mod m to base a exist only if a is a primitive root of m.

Why it is useful in cryptography

Easy: given g, x, p, compute y = gˣ mod p. At worst x multiplications; faster methods exist (Ch. 9).
Hard: given y, g, p, find x. Roughly as hard as factoring for RSA. Fastest known method is on the order of e^((ln p)^(1/3) (ln ln p)^(2/3)) — infeasible for large primes.

2.9Key Terms

The chapter’s key-term list (Section 2.9), plus terms needed to understand them.

Divisor
Nonzero b is a divisor of a (b | a) if a = mb for some integer m.
Residue
The remainder r in a = qn + r, 0 ≤ r < n; also a mod n.
Modulus
The positive integer n in a mod n.
Congruent mod n
a ≡ b (mod n) when a mod n = b mod n; equivalently n | (a − b).
Modular arithmetic
Addition, subtraction, multiplication carried out within Zn = {0, …, n − 1}, reducing mod n.
Greatest common divisor
Largest integer dividing both a and b; gcd(a, 0) = |a|.
Relatively prime
gcd(a, b) = 1.
Euclidean algorithm
Computes gcd by repeating gcd(a, b) = gcd(b, a mod b) until the remainder is 0.
Commutative
Order of operands doesn’t matter: (w + x) mod n = (x + w) mod n, likewise for ×.
Identity element
Leaves values unchanged: 0 for addition, 1 for multiplication.
Prime number
Integer p > 1 whose only divisors are ±1, ±p.
Composite number
Integer > 1 that is not prime.
Fermat’s theorem
a^(p−1) ≡ 1 (mod p) for prime p not dividing a.
Euler’s totient function
φ(n): count of positive integers < n relatively prime to n.
Euler’s theorem
a^φ(n) ≡ 1 (mod n) when gcd(a, n) = 1.
Bijection
One-to-one correspondence between two sets.
Chinese remainder theorem
With pairwise relatively prime moduli, A ∈ ZM ↔ (A mod m₁, …, A mod mₖ) is a bijection that preserves +, −, ×.
Order
Least m > 0 with a^m ≡ 1 (mod n).
Primitive root
An a whose order mod n is φ(n).
Discrete logarithm
The exponent i with b ≡ aⁱ (mod p) for primitive root a; dloga,p(b).
Index
Another name for the discrete logarithm.

2.9Review Questions

Questions 2.1–2.8 from the book. Answer first, then open to check.

2.1 What does it mean to say that b is a divisor of a?

b is nonzero and a = mb for some integer m; dividing a by b leaves no remainder.

2.2 What is the meaning of the expression “a divides b”?

a | b: a is nonzero and b = ma for some integer m.

2.3 What is the difference between modular arithmetic and ordinary arithmetic?

Modular arithmetic works within Zn = {0, …, n − 1}, reducing results mod n. Addition, subtraction and multiplication rules carry over, but cancellation in multiplication (Eq. 2.5) holds only when the factor is relatively prime to n, and a multiplicative inverse exists only for integers relatively prime to n.

2.4 What is a prime number?

An integer p > 1 whose only divisors are ±1 and ±p.

2.5 What is Euler’s totient function?

φ(n), the number of positive integers less than n and relatively prime to n (φ(1) = 1 by convention). φ(p) = p − 1 for prime p; φ(pq) = (p − 1)(q − 1) for distinct primes.

2.6 Miller–Rabin can show a number is not prime but cannot prove it is prime. How can it be used to test for primality?

Run TEST repeatedly with randomly chosen bases a. Any “composite” result proves n is composite. Each run lets a composite slip through with probability < 1/4, so after t “inconclusive” results the error is < (1/4)ᵗ; for large enough t, accept n as prime.

2.7 What is a primitive root of a number?

An integer a whose order mod n equals φ(n), the highest possible. Its powers a, a², …, a^φ(n) are distinct mod n; for a prime p they produce every integer 1 … p − 1.

2.8 What is the difference between an index and a discrete logarithm?

None. They are two names for the same concept: the exponent i such that b ≡ aⁱ (mod p) for a primitive root a.
